# HAZARA UX

Portrait column, max width 480px. The same stage is centered on a wide window.

## Screens

- Home: name, How to play (scrolls to the rulebook on the same page), Play with friends, Play online (visible, off, labeled Soon), try the cards on this device, return to a saved table. The rulebook shows the six combinations with card faces, one capture example, the spare, and a few tricks. The How to play button scrolls to the rulebook inline on the landing page.
- Lobby: large room code, Copy, Share (copies an invite and a `?room=` link), four seats, host mark, match length, Start disabled with "Need N more players".
- Arrangement: score line, seat chips, four sets, two-row tray, Undo, Sort sets, Ready hold. There is no play clock. Each set name and combination also shows the Hindi table word (ट्रॉय, कलर रन, रन, कलर, जोड़ी, इंडी, and इक्का, बादशाह, रानी). Live edits show Unsaved, then Saved, then Locked.
- Reveal: one set at a time, with the cards face-up in play order, a sentence for the winner or the tie, and a Hindi label for the combination. The server dwell is 4.5 seconds, 6 seconds for the spare set.
- Summary: who took each set, running totals, next dealer name, "This deal is 360 points." The host starts the next deal when ready. Match end has Play again and Home.
- Table talk: emoji, a short line, soundboard clips, and a voice note. They play live for the people at the table and are not saved.
- Reconnect: "Reconnecting… your hand is safe on the server." A locked hand adds "You're still locked in." The socket sends a keep-alive every 10 seconds.

Coach marks appear on the first live deal: tap then set, strongest on top, Ready locks.

Card faces are the Judgement public-domain PNG deck. There is no computer player and no public queue.
